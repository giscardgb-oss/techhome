Mise en ligne (connexion GitHub)

Le site est hébergé gratuitement sur GitHub Pages. Pour que le bouton « Publier » mette vos produits en ligne, l’administration a besoin d’une clé d’accès GitHub. Cette clé reste dans ce navigateur, ne la partagez avec personne.

  1. Sur GitHub, ouvrez Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Choisissez uniquement le dépôt du site, puis donnez l’autorisation « Contents : Read and write ».
  3. Copiez la clé et collez-la ci-dessous avec le nom de votre compte et du dépôt.
